# 사전등록 v0.3.0: 구현 상태와 서버 연동

- 웹: 새 사건 등록, 발생시각, GPS 좌표/정확도, 직접 수정 가능한 도로명/지번주소, 사건유형, 차량번호, 음성 녹음(IndexedDB), 지원 브라우저 음성 인식, 원문 보존, 규칙 기반 신고 초안, 브라우저 저장, 목록/불러오기, 신고서 연결, 발생시각 전후 5분 영상 후보 검색.
- 운전 중 화면 조작 금지. PWA의 화면 잠금 상태 음성 호출/상시 청취/백그라운드 녹음은 미지원. 별도 Android 포그라운드 서비스와 사용자 동의 필요.
- AI 문장 정리: 미연결. 서버측 LLM API와 사용자의 초안 검토/승인 기능이 필요. 현재 버튼은 AI가 아닌 규칙 기반 초안.
- 클라우드: 미연결. 사용자에게 지정받은 Supabase 프로젝트가 없으므로 운영 DB/Storage를 변경하지 않음. SQL은 배포 전 검토용이며 실제 실행하지 않음. 서버 인증과 RLS, 사용자별 Storage 정책, 음성파일 업로드/복구, 충돌해결, 삭제/보관정책이 구현되기 전에는 클라우드 동기화 완료라고 표시하지 않음.
- 국내 도로명/지번 역지오코딩: 미연결. 서버에서 국내 주소 API 인증키를 보관하고 동일 출처 HTTPS 엔드포인트를 제공해야 함. GPS 원본/주소/사용자 확인 장소를 별도로 보존.
- 로컬 저장은 브라우저 저장소 삭제 시 소실될 수 있으며 기기 간 동기화되지 않음.
- 서버 연결 전 사용자의 위치·녹음·음성 텍스트는 외부 서비스로 업로드하지 않음. 다만 브라우저의 SpeechRecognition 엔진은 서비스 제공자 측에서 음성을 처리할 수 있으므로 서비스별 개인정보 처리 고지가 필요.
- 테스트: GitHub 소스 반영만 수행. GitHub Pages 배포 성공/실기기 마이크·GPS·설치 동작은 아직 미검증.
