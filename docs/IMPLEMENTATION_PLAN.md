# 구현 계획

## 1. Android 우선
Kotlin + Jetpack Compose, Storage Access Framework로 외장 저장소 폴더 접근. MediaMetadataRetriever/Media3를 이용한 재생·메타데이터 탐색. 파일 시간은 신뢰도와 출처를 함께 표시. 프레임 추출 및 A/B 구간 MP4 내보내기는 호환 코덱과 정확한 경계 확인 필요.

## 2. 신고 편집
안전신문고 캡처 기준: 불법주정차/자동차·교통위반 유형; 발생지역, 사진, 신고 내용(5~900자), 차량번호, 발생일자/시간. 메뉴 추천과 법령 검증 결과는 별도로 구분. 복사 버튼을 각 텍스트 항목에 제공.

## 3. 동기화
신고 건별 고유 ID, revision, updated_at, 첨부파일 해시, 로컬 업로드 큐를 정의. Google OAuth로 사용자가 지정한 Drive 폴더에 저장. PC 웹은 인증 후 동일 프로젝트 열람. 충돌은 버전 비교 후 사용자 선택; 원본 자동 삭제 금지.

## 4. 품질 게이트
Android 실제 USB 장치 접근, 영상 재생·프레임 정밀도, 오디오 포함/제외, 프로젝트 복구, PC 동기화, API 키 비노출, 신고 내용 글자 수, 접근성, GitHub Actions APK 빌드 및 기기 설치 검증.
