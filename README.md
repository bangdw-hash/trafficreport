# 손끝 교통신고 AI (Traffic Report)

개인용 Android 앱 및 PC 웹앱 개발 저장소입니다.

## 확정 요구사항
- Android: USB/외장 저장소에서 영상 선택, 촬영시각 기반 복수 영상 검색(메타데이터 부재 시 확인 필요), 전후방 목록 재생, 가로 전체화면, 핀치 줌, 프레임 이동
- A–B 구간 선택, 구간 반복 및 배속, 오디오 포함/제외 MP4 내보내기, 원본 보존
- 증거 프레임 캡처, 화살표·점선·둥근 영역 등 편집 객체, 프로젝트 저장
- 안전신문고 실제 항목 기반 교통위반 신고 문안 작성 및 항목별 복사(내용 5~900자)
- 국가법령정보센터의 현행 조문 검증 후 법령 근거 제시; 불확실한 위반 단정 금지
- Google Drive에 선택된 증거와 편집 프로젝트 동기화, PC 웹앱에서 조회·수정
- Android 로컬 실행은 비밀번호 없이, 웹은 본인 인증 적용

## 데이터 및 보안
- 원본 블랙박스 영상은 기본적으로 기기/외장 메모리에 유지합니다.
- API 키·OAuth 비밀값·개인정보·증거영상은 GitHub에 커밋하지 않습니다.
- Drive 연동은 OAuth 동의와 적절한 최소 권한 범위가 필요합니다.
- 안전신문고 신고 제출 및 휴대전화 인증은 공식 서비스에서 직접 수행합니다.

## 현재 상태
요구사항 및 초기 개발 기록만 반영되었습니다. APK/웹앱 구현·빌드·배포·실기기 검증은 아직 완료되지 않았습니다.
